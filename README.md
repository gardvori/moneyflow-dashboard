# 💰 MoneyFlow — Personal Finance Dashboard

A beautiful, fully client-side personal finance tracker. No server, no database, no sign-up. All data stays in your browser.

## ✨ Features

- **📈 Income & Expense Tracking** — Log transactions with categories, dates, and descriptions
- **📊 Visual Charts** — 7-day bar chart comparing daily income vs expenses
- **🎯 Budget Monitoring** — Set a monthly budget and track spending progress with visual indicator
- **📂 Category Breakdown** — See where your money goes, sorted by spending
- **💾 Local Storage** — All data persisted in your browser, never leaves your device
- **⬇ Export** — Download your data as JSON for backup
- **🌙 Dark Theme** — Easy on the eyes with a modern dark UI
- **📱 Responsive** — Works on desktop and mobile

## 🚀 Live Demo

**https://gardvori.github.io/moneyflow-dashboard/**

## 🛠 Tech Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- Canvas API for charts
- LocalStorage for data persistence
- Zero dependencies

## 📖 Usage

1. Open the app in your browser
2. Choose Income or Expense type
3. Enter description, amount, category, and date
4. Click "Add Transaction"
5. View summary cards, charts, and category breakdown
6. Set your monthly budget in Settings
7. Export your data anytime

## 🔒 Privacy

All data is stored locally in your browser. No data is sent to any server. Your financial data never leaves your device.
